1) AI Career Engine - Phase 1 Core (Week 1)
Add Job Description input in editor flow.
Build Tailor Resume action: user goal + JD -> AI suggestions per section.
Keep human in control: show suggestions as “accept/reject,” never auto-overwrite.
2) WOW Feature: Auto-Enhance Experience (Week 1-2)
Add one-click button beside each experience bullet: “Enhance with AI”.
Return improved bullet with stronger verbs, clearer scope, measurable impact.
Show side-by-side diff/highlight so users trust changes.
Add “tone” selector (concise/impactful/technical) for personalization.
3) ATS Scoring (Week 2)
Start with transparent scoring categories, not magic number:
Keyword match
Action verbs
Quantified achievements
Structure/completeness
Display score + exact reasons + “how to improve” tasks.
Recompute quickly after edits to create iteration loop.
4) Job Targeting Mode (Week 2-3)
Inputs: target role + seniority.
Use presets to adjust wording, suggested skills, and bullet style.
Provide role-specific section tips (“For frontend roles, emphasize X/Y/Z”).
5) UI/UX Upgrade (Parallel, Week 1-3)
Convert current form into step flow:
Profile
Experience/Education
AI Improve
ATS Review
Preview/Export
Keep live preview visible on desktop.
Add loading states/skeletons for every AI call.
6) Performance Work (Parallel)
Let users start without forced login.
Lazy-load heavy editor/preview components.
Cache templates and recent AI outputs.
Set target: first useful result under 60s.
7) Monetization Layer (After value is proven)

8) CV -> Public Profile (Phase 3)
Generate hresume.pro/{username} from CV data.
